Minecraft - Enhanced Mason Trades is a minecraft mod that adds new trades for masons. The mod is designed to be used with Fabric. It currently adds trades for Pascked Mud, Bricks, Mud Bricks, Tuff, Plain Terracotta and Calcite to the mason villager's trade table. The mod has been downloaded over 1.5k times since its release in October 2024.

## 💻 Technologies

The project uses of the following technologies:

- Git
- Java 17+ (Build uses 17)
- Gradle
- Fabric
- GitHub Actions
