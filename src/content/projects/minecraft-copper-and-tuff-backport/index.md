Minecraft - Copper and Tuff Backport is a minecraft mod that backports the Copper and Tuff blocks from Minecraft 1.21 to Minecraft 1.19. The mod is designed to be used with Fabric. I took over after the previous creator stopped work on it. I have since doubled the amount of content in the mod and recently passed 3k downloads.

## 💻 Technologies

The project uses of the following technologies:

- Git
- Java 17+ (Build uses 21)
- Gradle
- Fabric
- GitHub Actions
