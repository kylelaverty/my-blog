Minecraft - Villager Professions Plus is a minecraft mod that adds new professions for villagers, sometimes with new profession stations. The mod is designed to be used with Fabric. So far, I have created one new profession, the associated skin and the associated workstation. It hit 3.5k downloads within the last month.

## 💻 Technologies

The project uses of the following technologies:

- Git
- Java 17+ (Build uses 17)
- Gradle
- Fabric
- GitHub Actions
